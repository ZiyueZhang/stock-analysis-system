# 交互简化：合并 Ticker 输入与运行按钮

根据您的要求，我将把原本分散的 "Ticker 配置" 和 "运行按钮" 整合进底部的对话输入框，实现类似 ChatGPT/Claude 的自然语言交互体验。

## 核心设计 (Design)

### 1. 移除冗余 UI
*   从右侧控制面板 (`Control Panel`) 中**移除** "Target Ticker" 输入框。
*   从右侧控制面板中**移除** "Run Analysis" 大按钮。
*   右侧面板将仅用于 **"Select Strategy"** (策略选择) 和 **"Strategy Detail"** (详情展示)。

### 2. 增强型输入框 (Enhanced Chat Input)
*   **输入逻辑升级**:
    *   **初始状态 (Start Analysis)**: 当没有 Ticker 时，输入框 placeholder 提示 *"Enter ticker (e.g. NVDA) to start analysis..."*。用户输入 Ticker 并发送后，自动触发分析。
    *   **追问状态 (Follow-up)**: 分析完成后，输入框恢复为普通聊天模式。
*   **Ticker 解析**:
    *   用户可以直接输入 `NVDA`，也可以输入 `Analyze NVDA`。前端做一个简单的正则提取 (或者直接将输入作为 Ticker)。
    *   为了简化，我们将采用**"显式 Ticker 模式"**：如果是新会话且未设置 Ticker，用户的第一次输入将被视为 Ticker。

### 3. 数据流变更 (`App.tsx`)
*   `handleSendMessage`:
    *   **Case A (New Session)**: 如果 `!ticker`，将用户输入 (`text`) 设为 `ticker` -> 触发 `handleStreamAnalyze`。
    *   **Case B (Existing Session)**: 如果 `ticker` 已存在，执行原有的追问逻辑。

## 实施计划
1.  **UI 清理**: 修改 `App.tsx`，删除右侧面板的 Ticker Input 和 Run Button。
2.  **逻辑重构**: 修改 `handleSendMessage` 函数，增加对 Ticker 的自动捕获和流程分发。
3.  **ChatWindow 提示优化**: 修改 `ChatWindow` 的 placeholder，根据当前状态动态变化 (e.g., "Enter stock ticker..." vs "Ask a follow-up question...").
