## 2. 版本控制 (Git Initialization)

### A. 环境清理与准备
*   检查 `.gitignore`，确保覆盖：
    *   `__pycache__/`, `.venv/`, `.env` (敏感信息)
    *   `node_modules/`, `dist/`
    *   `*.db` (SQLite 数据库)
    *   `.DS_Store`, `.idea/`

### B. Git 初始化流程
1.  `git init`
2.  `git add .`
3.  `git commit -m "v1.0.0: Initial release with Strategy Decoupling, Web Search, and Enhanced UI"`
4.  `git tag v1.0.0`
5.  (可选) 如果用户提供了远程仓库 URL，则进行关联。
