# Ticker 校验逻辑优化

您遇到的问题是因为当前的 Ticker 自动识别逻辑过于严格，只允许 6 位以下的纯大写字母 (`/^[A-Z]+$/`)。这导致输入中文（如“阳关电源”）或其他非标准格式时被拦截。

## 解决方案
我们将放宽 Ticker 的校验逻辑，允许用户输入更自由的内容作为分析目标（Tavily 和 LLM 通常能处理公司名称）。

### 修改计划
1.  **放宽正则校验**: 在 `App.tsx` 的 `handleSendMessage` 中，将 Ticker 识别逻辑修改为：
    *   **移除纯字母限制**: 允许中文、数字等。
    *   **长度限制放宽**: 比如放宽到 20 字符以内（覆盖大多数公司名）。
    *   **直接透传**: 甚至可以直接将用户的第一次输入作为 "Search Query" 传递给后端，而不强制要求是 Ticker 代码。

2.  **具体修改**:
    *   如果不匹配 Ticker 格式，不再弹窗 `alert` 阻止。
    *   而是将输入内容直接视为 `inputTicker` (即分析目标)。
    *   例如输入 "阳关电源"，系统将执行 `Analyze 阳关电源`。

### 预期行为
*   输入 "NVDA" -> 识别为 Ticker -> Analyze NVDA
*   输入 "阳关电源" -> 识别为 Query -> Analyze 阳关电源
*   输入 "分析一下特斯拉" -> 识别为 Query -> Analyze 分析一下特斯拉
