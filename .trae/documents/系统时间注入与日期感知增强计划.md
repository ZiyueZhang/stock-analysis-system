# 系统时间注入与日期感知增强计划

用户反馈 LLM 无法感知当前的准确日期（仍停留在训练数据的过去时间），这在金融分析（如“今天股价”、“上周新闻”）中是致命缺陷。

## 解决方案

最简单且有效的方法是在 **System Prompt** 中动态注入当前的系统日期和时间。这样 LLM 在推理时就拥有了正确的时间锚点，从而能够正确解析 "today", "yesterday", "last week" 等相对时间词。

### 1. 动态 System Prompt 注入
*   **当前现状**: 前端硬编码了 `system` 消息：`{ role: 'system', content: 'You are a helpful financial assistant.' }`。
*   **改进**:
    *   在前端 (`App.tsx`) 发送请求前，动态生成包含当前时间的 System Prompt。
    *   **格式**: `You are a helpful financial assistant. Today is {Current Date} (Day of Week). Current Time: {Time}.`

### 2. 后端辅助 (可选但推荐)
*   虽然前端注入已足够，但在 `UnifiedLLMService` 初始化新会话时，也可以在后端自动插入一条带有时间戳的隐藏 System Message，作为双重保险（特别是对于纯后端触发的任务）。
*   鉴于当前架构主要由前端驱动对话历史，优先修改前端。

### 3. 实施步骤
1.  **修改 `App.tsx`**:
    *   创建一个辅助函数 `getSystemPrompt()`，返回带有 `new Date()` 信息的字符串。
    *   在 `handleStreamAnalyze` 和 `handleSendMessage` 中，将硬编码的 System Prompt 替换为此动态生成的 Prompt。

## 验证
*   询问 LLM: "What is today's date?" -> 应返回当前实际日期。
*   询问 LLM: "Search for news from last Friday." -> LLM 应能基于当前日期推算出上周五的具体日期并调用搜索工具。
