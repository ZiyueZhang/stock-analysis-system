# 功能增强实施计划 (v2.1 - 修正版)

收到，已移除 "Clear Button" 需求，改为纯粹的 **单选切换 (Toggle)** 交互。

## 1. 历史会话重命名 (Rename Conversation)
*   **后端**:
    *   新增 `PATCH /api/conversations/{id}` 接口，用于更新标题。
*   **前端 Sidebar**:
    *   **UI**: 在会话项上添加编辑图标 (Pencil)。
    *   **交互**: 点击编辑 -> 标题变为 Input 框 -> 失去焦点/回车保存 -> 调用 API。

## 2. 策略选择机制优化 (Flexible Strategy)
*   **可选策略**:
    *   修改 `handleSendMessage`：移除“未选策略时强制弹窗”的逻辑。
    *   如果未选策略，直接发送用户输入，不附加 Prompt 模板。
*   **历史会话支持**:
    *   确保切换会话 (`activeConversationId` 变化) 时，右侧面板状态正确重置或保留（取决于是否需要记忆上次策略，建议切会话时重置 `selectedPrompt` 为 null，除非后端记录了该会话绑定的策略 - *注：当前 DB 模型暂未绑定策略，故每次切会话重置为 null 较合理*）。

## 3. 策略选择交互 (Toggle Logic)
*   **Toggle**:
    *   修改 `App.tsx` 中的 `handleSelectPrompt(prompt)`。
    *   逻辑：`if (selectedPrompt?.id === prompt.id) setSelectedPrompt(null); else setSelectedPrompt(prompt);`
    *   **视觉**: 选中状态保持高亮，取消选中恢复默认。

## 实施步骤
1.  **后端**: 实现 `PATCH` 接口。
2.  **前端 Sidebar**: 实现重命名功能。
3.  **前端 App**:
    *   更新策略点击逻辑 (Toggle)。
    *   更新发送逻辑 (允许无策略)。
