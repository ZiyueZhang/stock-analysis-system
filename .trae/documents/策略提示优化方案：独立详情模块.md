# 策略提示优化方案：独立详情模块 (Right Panel)

经过评估，我建议采用 **"右侧独立详情模块"** 方案，而不是调整 Tooltip 的 z-index。

**原因 (Rationale):**
1.  **空间限制**: Prompt 内容通常很长（包含多个章节和变量），悬浮 Tooltip 即使调整了 z-index，也很容易遮挡用户正在操作的输入框或列表，导致体验不佳。
2.  **交互性**: Tooltip 无法进行复制、滚动或复杂的交互操作。独立面板可以提供更稳定的阅读体验。
3.  **可扩展性**: 未来可以在此面板中添加 "编辑 Prompt" 或 "Prompt 参数配置" 功能。

## 实施计划

### 1. 布局重构 (Layout)
*   **当前布局**: `Sidebar (Left)` | `Config (Middle)` | `ChatWindow (Right)`
*   **新布局**: `Sidebar (Left)` | `ChatWindow (Middle)` | `Config/Detail (Right)`
    *   将原本的 `Config` (Middle) 移动到右侧，作为常驻的 **"Control Panel"**。
    *   聊天窗口占据中央主要区域。

### 2. 功能实现
*   **右侧面板 (Control Panel)**:
    *   **Top**: 策略选择列表 (保留)。
    *   **Bottom**: "Strategy Details" 区域。当选中某个策略时，在此处展示完整的高亮 Prompt 内容。
    *   **Action**: "Run Analysis" 按钮和 Ticker 输入框也整合在此面板。
*   **状态联动**: 点击策略列表 -> 更新 `selectedPrompt` -> 右侧详情区自动展开并显示内容。

### 3. 代码变更点
*   `App.tsx`:
    *   调整 Flex 布局顺序。
    *   移除旧的 `Tooltip` 代码。
    *   在右侧面板底部新增 `<div className="strategy-preview">`。

此方案将彻底解决遮挡问题，并提供更专业的 "IDE 风格" 布局。
