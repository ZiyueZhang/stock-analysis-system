# 功能增强实施计划

## 1. 历史记录删除功能 (Delete History)
*   **API 扩展**:
    *   在 `backend/main.py` 添加 `DELETE /api/conversations/{id}` 接口，物理删除数据库中的 Conversation 及其关联 Messages。
*   **前端交互**:
    *   修改 `Sidebar.tsx`: 为每个会话项添加悬浮显示的删除图标 (Trash Icon)。
    *   交互逻辑: 点击 -> `window.confirm` (简化版确认) -> 调用 API -> 成功后从 `conversations` 状态中过滤移除。
    *   *注*: 批量删除和撤销功能较为复杂，本次优先实现基础的单条删除与确认功能，确保核心需求落地。

## 2. 自由输入对话增强 (Free Input Chat)
*   **UI 重构**:
    *   修改 `ChatWindow.tsx`: 在底部添加固定的输入区域 (`InputArea`)。
    *   组件: `textarea` (支持 auto-resize), `Send` 按钮。
    *   快捷键: 监听 `onKeyDown` 实现 Ctrl+Enter 发送。
*   **逻辑集成**:
    *   不再仅依赖 "Select Strategy" -> "Run Analysis" 的流程。
    *   允许用户在现有会话中继续追问 (Follow-up questions)。
    *   API 调用: 复用 `streamChat`，但跳过 Prompt 模板封装，直接发送用户输入。

## 3. Strategy Prompt 悬浮提示 (Tooltip)
*   **组件开发**:
    *   在 `App.tsx` 的 Prompt 列表渲染部分引入 Tooltip 逻辑。
    *   由于原生 title 属性不支持 HTML/高亮，将使用自定义 `div` 浮层或简单的 CSS Hover 方案。
*   **内容高亮**:
    *   解析 Prompt 文本，正则匹配 `{{variable}}` 或 `${variable}`，用 `<span class="bg-yellow-200">` 包裹。
    *   实现延迟显示逻辑 (CSS `transition-delay` 或 React `onMouseEnter` timer)。
